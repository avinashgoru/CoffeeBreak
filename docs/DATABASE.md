# Database Architecture

## Technology

- **MongoDB** (Mongoose ODM)

## Future Collections (Phase 1+)

- **Products**: Stores coffee items (Espresso, Mocha, etc.) with price, image references, and details.
- **Users**: Authentication details, roles.
- **Orders**: Cart and checkout history.
- **Reviews/Testimonials**: Customer feedback displayed on the landing page.

_Note: Phase 0 only establishes the connection string and Mongoose setup. No models are defined yet._
