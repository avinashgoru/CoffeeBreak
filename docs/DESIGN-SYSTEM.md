# Design System Strategy

## Colors

Extracted precisely from the reference image:

- Primary Dark: `#2B1611`
- Primary Medium: `#3E2723`
- Cream Backgrounds: `#FFF8E1`
- Gold Accent: `#D4AF37`

## Typography

- Display Font: `Playfair Display`
- Script Font: `Great Vibes` (for coffee branding and decorative elements)
- Body Font: `Inter`

## Component Strategy

- **Buttons**: Reusable button component supporting outlined and filled variants.
- **Cards**: Feature and product cards using shared layout components.
- **Section Spacing**: Strictly controlled via `var(--spacing-section)`.
